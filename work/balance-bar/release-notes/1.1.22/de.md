# Neuigkeiten in BalanceBar 1.1.22

## Update-Einstellungen

- Wähle **Stabil** oder **Betatest** in einem eigenen Update-Kanal.
- Suche in einer separaten Zeile nach Updates.
- Wenn eine neue Version verfügbar ist, kannst du die **Versionshinweise** ansehen oder sie herunterladen und installieren.

Die Hinweise werden mit sicherem nativem `Markdown` dargestellt. [Die Version auf GitHub ansehen](https://github.com/huanmeng06/BalanceBar/releases/tag/v1.1.22) für die ursprünglichen Details.
