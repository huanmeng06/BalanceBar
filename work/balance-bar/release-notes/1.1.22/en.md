# What's new in BalanceBar 1.1.22

## Update settings

- Check for updates from a separate row.
- When an update is available, open these **release notes** or **Download and Install** it.

The notes use safe native `Markdown` rendering. [View the GitHub release](https://github.com/huanmeng06/BalanceBar/releases/tag/v1.1.22) for the original details.
