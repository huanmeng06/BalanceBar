### 初步成因与置信度

- **已确认**：本次 Mod 有新文件写入；界面截图时间比该文件旧。安装/写入阶段可以单独确认通过。
- **已确认的机制**：同值、同周期快照被安全去重；界面展示最后可信受理时间。
- **本次具体因果为高概率，仍待验证**：两条极短回复可能未推动用量百分比，导致新的 `updated_at` 未形成新证据。未保存 03:33 那次已采纳的完整指纹，也未读取运行中进程的 replay counter，不能断言本次一定命中了这条分支；仍需排除其它处理/展示未更新路径。
- 快照匹配 CLI 账号不等于已独立核验 BalanceBar 当前账号；不据此放宽账号检查。

### 安全边界与后续验收

- 不要求用户重装、清配置、篡改快照或额外消耗大量额度来推动百分比。
- 不移除 replay suppression，不把文件 mtime/新时间戳冒充可信受理，不改变官方限流、账号/周期验证或成功门控。
- 如需展示最近收包状态，应与“最近可信额度证据”明确区分，不能反向影响新鲜度、调度或合并判定。
- 验收：同值新快照、真实用量变化、旧文件重扫、账号/周期拒绝各有准确的时间/状态解释；只有可信受理驱动额度成功，重复数据不延长可信新鲜度。
- 待补充：运行时去重计数/脱敏指纹差异证据，以及展示口径的维护者决定。

本条仅记录和分析；未修改生产代码，未提交、推送、构建或发布。此前“发两次 OK 后界面时间必定更新”的手测预期需要修正。

## BUG-20261025-02：卸载完成后管理页显示未安装，但高级设置卡片仍显示“已启用”和旧数据时间

- 状态：已修复，人工回归 PASS。
- 严重性：中（删除后的安装状态误导，用户无法确认操作结果；未发现实际卸载失败）。
- 发现版本：开发版 1.7.39（208），App build SHA `79a6fdfd`。
- 分支/记录时 HEAD：`codex/issue-597-mod-user-install` / `cba6970a`（PR #603）。
- 已确认范围：CLI 2.1.291 用户手测；崩溃与跨版本影响尚未验证。

### 用户现象与复现

1. 在已启用状态打开管理窗口，明确确认卸载。
2. 卸载完成后重新打开管理窗口，显示安装说明和“一键安装”，说明用户级安装已移除。
3. 返回高级页，卡片仍显示“BalanceBar Mod 状态：已启用”、绿色圆点和旧“最新数据”时间。

预期：卸载完成后，高级卡片与管理窗口使用同一真实状态；旧已启用状态和受理时间不得继续显示。

### 直接证据

- 用户附件 1 显示卸载后管理窗口已进入安装说明，按钮为“复制命令 / 稍后 / 一键安装”。
- 用户附件 2 同轮显示高级卡片仍为“已启用”和“最新数据：03:33:23”。
- 用户执行后的只读 CLI 查询 `plugin list --json` 与 `marketplace list --json`：仅剩 `claude-hud` 和 `swift-lsp`，没有 `balancebar-mod@balancebar-mods` 或 `balancebar-mods` 来源。直接确认卸载/来源移除已完成，现象是 UI 刷新错误。

### 代码证据与根因

- `Sources/UI/Dashboard/DashboardCompositionController.swift`：Mod 卡片已从 General 移到 Advanced，但 `refreshModSync()` 仍用 `canUpdateSettingsPage(.general)` 作门槛。高级页可见时返回 false，协调器和管道更新到达 App 后无法写回卡片；管理窗口另有实时 `syncProvider`，所以能正确显示未安装。
- 同一路径在离开高级页时丢弃状态更新；返回缓存的高级页时，激活逻辑对 `.advanced` 不做刷新，卡片保留旧值。
- 初步成因置信度：**已确认**。3 个精确回归测试在修复前稳定复现 6 个失败断言；把刷新目标改为 Advanced 并在高级页激活时刷新后，3 个测试全部通过。

### 修复与回归

- `refreshModSync()` 改为仅在 Advanced 可见或全局搜索投影活跃时刷新。
- 从其它设置页回到缓存的 Advanced 时，在页面激活阶段拉取当前 Mod 状态和操作进度。
- 回归覆盖：可见高级卡片卸载后清除已启用时间；离开再返回缓存页；全局搜索内更新；新可信证据时间能更新已显示的卡片。
- 修复前：3 tests，6 failures。修复后：3 tests，0 failures。
- 人工回归：用户使用开发版 `1.7.40 / 209`（可执行文件 SHA-256 `bc559d80221ee49db46ddde5c4d1c2fde9cd9212de2bbc999cb851f5712e418a`）完成本地安装、确认待数据状态；打开管理窗后将主窗口留在 General，执行卸载，再返回 Advanced。卡片立即显示“未开启”，无绿色点和旧时间；关闭管理窗、General↔Advanced 往返及全局搜索结果均保持一致。
- 只读核对：人工回归结束后 `claude plugin list --json` 与 `claude plugin marketplace list --json` 均无 BalanceBar 条目，和 UI 显示一致。

### 安全边界与验收

- 不伪造未安装状态；检测结果仍来自现有 `ModSyncCoordinator` / `ModSyncDetector`。
- 不放宽快照可信度、账号/周期校验或安装/卸载命令语义。
- 用新构建重新执行卸载，管理窗口与高级卡片必须同时显示未安装，旧受理时间消失；切到其它页再返回、用全局搜索显示该卡片时也必须一致。
