## 范围与基线

- 本清单覆盖审计追踪到的全部 217 个 Dashboard 设置/辅助文案条目：导航、窗口、About、Advanced（含 OpenCodex、Diagnostics、Logs）、General（含 Refresh 与 Refresh Settings）、Menu Bar、Menu、Providers 和 Status Links 编辑器。
- 当前实现基于已重新读取的 `origin/main`（#212 已合并）；本次将审计标记为需复核的 40 个设置键在九种语言中重写，并为三处产品自有硬编码补充集中式键。
- 简体中文补充审阅表的前 88 条全部纳入：其中第 43–82 条对应下方设置文案，第 1–42 条与第 83–88 条更新为运行时/状态提示。第 89 条及之后不属于本次范围，保持不变。
- 所有改动仅限本地化资源、集中式本地化键、三处文案调用和回归测试；不改偏好键、默认值、迁移、控件类型、回调、布局结构、可访问性标识或业务逻辑。

## 术语与决策

| 概念 | 决策 |
| --- | --- |
| Provider | 面向用户时说明为所选/当前服务商（各语言采用对应母语术语），避免把实现角色名直接暴露为标题。 |
| Balance / quota | Balance 表示账户余额；quota 表示 5 小时/7 日等额度周期，避免两者混用。 |
| Offset / position | 设置标题描述可见的上下位置；保留滑块范围、方向和默认值。 |
| Fallback polling | 称为备用检查频率，并说明事件通知通常会即时同步。 |
| Agent / task status | 用任务状态表达用户能观察到的结果；不改变任务检测逻辑。 |
| Status links / Open Project | 说明服务状态链接和快捷入口的实际结果，而不是内部页面名称。 |
